# Sample Data

This folder holds 2–3 representative GeoTIFF files for reproducibility 
testing without GEE access.

Files must follow the naming conventions below:
- All-network:   {WaterBody}_{Param}_MonthlyAvg_{YYYY-MM}.tif
- Khlong Nueng:  Khlong_Nueng_{Param}_{YYYY-MM}.tif

GeoTIFF specifications: WGS 84 (EPSG:4326), 30 m resolution, 
Float32, 1 band, NoData = NaN.

Full dataset available on request from the corresponding author.
